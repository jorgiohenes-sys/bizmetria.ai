# BizMetria.ai

BizMetria is a bilingual AI-powered business assessment platform for companies across industries.

## Approved product baseline

- Brand and domain: **BizMetria.ai**
- Public paid product: **BizMetria Business Assessment**
- Price: **$299 one-time**
- Launch languages: **English and Spanish**
- Voice architecture: **separate English and Spanish phone numbers**
- Primary funnel: free AI Opportunity Check → paid assessment → report consultation → separately priced implementation

## How to start a new project chat

1. Provide the chat with the current Master Brief.
2. Provide the Coordination Protocol and Decision Log.
3. Provide the dedicated workstream brief.
4. Ask the chat to state the versions it is using before starting work.
5. Require each completed work package to end with a Handoff Summary.
6. Route every proposed global change through Master Control.

## Governance

The GitHub specifications are the source of truth. A chat conversation may explore ideas, but global changes are not approved until they are recorded in the Decision Log and reflected in the relevant versioned specification.
