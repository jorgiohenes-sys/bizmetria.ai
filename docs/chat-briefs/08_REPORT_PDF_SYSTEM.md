# Chat Brief 08 — Report and PDF System

**Role:** Owner of the customer-facing assessment report, templates, rendering, review workflow, and final PDF  
**Required context:** Master Brief, Product deliverables, Analysis output schema, Brand system, Legal disclaimers

## Mission

Turn approved structured analysis into a professional, clear, bilingual report that helps the customer understand priorities and naturally leads to a results consultation and possible implementation project.

## Responsibilities

- Define report architecture and section order
- Design English and Spanish templates
- Map structured analysis fields to report elements
- Design Impact vs. Effort and roadmap visualizations
- Present evidence, assumptions, and confidence appropriately
- Create human-review and edit workflow
- Support partial section regeneration without corrupting approved content
- Generate accessible, printable PDFs
- Define report-delivery metadata and version history

## Approved report themes

- Executive summary
- Business profile and current-state overview
- Major bottlenecks and evidence
- AI and automation opportunities
- Quick Wins
- Impact vs. Effort matrix
- Recommended tools or solution types when supported
- 30–90 day roadmap
- Expected qualitative benefits and limitations
- Recommended next step and consultation CTA

## Must not do

- Do not invent analysis missing from structured input
- Do not hide uncertainty
- Do not present estimates as guaranteed outcomes
- Do not expose internal prompts or private implementation notes
- Do not allow English and Spanish reports to differ in promised scope
- Do not automatically deliver during MVP before human approval

## Required deliverables

1. Report information architecture
2. English template
3. Spanish template
4. Report input schema mapping
5. Visual-component specification
6. PDF rendering requirements
7. Human-review checklist
8. Edit and regeneration workflow
9. Report version and audit-trail rules
10. Sample reports across multiple industries

## Acceptance criteria

- A nontechnical owner can understand the priorities
- Claims are traceable to the analysis output
- English and Spanish versions have equivalent completeness
- PDF layout works on screen and print
- Human reviewers can edit and approve efficiently
- The report contains a clear but nonaggressive next-step offer
