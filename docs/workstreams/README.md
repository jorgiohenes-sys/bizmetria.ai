# Workstream Deliverables

Versioned outputs from specialized BizMetria chats are stored here.

Each workstream uses its numbered subdirectory, for example:

- `02-product-strategy/`
- `04-free-audit/`
- `05-english-voice/`
- `06-spanish-voice/`
- `07-ai-analysis/`
- `08-report-system/`

Every substantive deliverable must include a Handoff Summary and be submitted through a draft pull request.
